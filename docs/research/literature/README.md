# Literature

Original materials from upstream's research. The source texts are not distributed with this
repository; only their provenance and download locations are recorded here. See
[decisions/repository-conventions.md](../../decisions/repository-conventions.md),
2026-09-26, for the reasoning.

| File | Source |
|---|---|
| `szczepanczyk-2023-jie-pseudocode-and-algorithms.pdf` | Szczepanczyk, M. (2023). *Journal of Information Economics* 1(3), 15. doi:10.58567/jie01030004 |
| `hahnel-szczepanczyk-weisdorf-2020-simulation-experiments-slides.pdf` | Hahnel, Szczepanczyk, Weisdorf, Systems Science Noon Seminar, 2020-12-04 |

Download locations for both:

```sh
curl -sSL -o szczepanczyk-2023-jie-pseudocode-and-algorithms.pdf   http://www.szcz.org/img/jie-paper-2023.pdf
curl -sSL -o hahnel-szczepanczyk-weisdorf-2020-simulation-experiments-slides.pdf   https://thenextrecession.wordpress.com/wp-content/uploads/2021/01/computersimulationexperimentsofparti_powerpoint.pdf
```

The slide PDF's text layer is corrupted (inter-character spacing is eaten), so text search
cannot find content; you have to look at the page images by page number. Wherever this
repository's documents cite the slides, they give the page number.
