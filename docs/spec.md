# 当前规则

本文只写现在成立的规则。理由在 `决策/`，进度在 `progress-decisions.md`。

项目尚无代码，以下是已经承诺、后续实现必须满足的约束。

## 范围

本库覆盖民主计划经济与参与式计划经济。库名 `cyberstride`。

机制层只收这个领域内的协调程序。**不实现市场机制**，`Economy` 不含货币收支、
市场出清残差这类市场专用字段。机制之间的对照基准是集中式最优参照解，不是市场基线。

## 核心抽象

库把一次计划过程拆成四个部分：

| 抽象 | 职责 |
|---|---|
| `Economy` | 数据模型：商品、单位、技术、禀赋、人口、生态约束、时间 |
| `Participant` | 给定信号，产出提案 |
| `Procedure` | 给定全部提案，产出新信号或最终计划 |
| `Evaluator` | 给定计划，产出可比指标 |

**抽象是否成立，判据只有一条**：parecon 的迭代调价、Cockshott 的劳动时间直接计算、
Kantorovich 式线性规划，三者能跑在同一个 `Economy` 上，并由同一个 `Evaluator` 打分。

## 可替换与不可替换

`Economy` 可扩展，不可替换。它一旦可插拔，跨研究的结果就不可比。

以下四项固定，不作为插件暴露：

- `Economy` 数据模型
- 守恒律与不变量检查
- 一组核心指标
- 确定性与种子化

以下属机制层，可插拔：`Procedure`、`Participant` 行为核、经济体生成器与数据加载器、
约束族、附加指标、输出后端、可视化。

## 不变量

任何 `Procedure` 产出的计划都要通过以下检查。检查在全局强制执行，不通过时把结果标为无效，
不照常输出。

- **物料平衡**：任一商品的消耗量不超过产出量与禀赋之和
- **预算恒等**：各参与者的支出与收入相符
- **非负性**：数量与价格不为负
- **价格零次齐次**：所有价格同比例缩放时，实物解不变（仅适用于带价格的机制）

## 确定性

同一份场景文件加同一个种子，产出逐位相同的结果。并行归约要用确定性分块，
不依赖线程数与调度顺序。

## 执行与存储

整个经济体常驻内存，采用列式 f64 数组。一轮迭代不碰磁盘：只在 run 开始时读、结束时写。

## 输出契约

Rust 侧只产出长格式（tidy）Arrow/Parquet，schema 带版本。绘图在 Python 层。

每次运行产出一份 run manifest，记录解析后的插件图、各插件版本与内容哈希、种子、
场景文件哈希。结果中的每个数字可回溯到 (场景哈希, 插件图, 种子, 迭代序号)。

## 装配期校验

每个插件声明它需要什么字段与能力、提供什么。整张装配图在开跑前校验。
跨语言边界（Rust 与 Python）会丢失类型系统的保护，所以这层 schema 校验是必需项。
