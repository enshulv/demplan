# 不变量与指标

## 2026-08-28

### 理论无关是基础层的硬约束

**决策**：基础层不得预设任何经济理论。凡是蕴含理论预设的东西——不变量、指标、行为方程——
一律做成可选工具，由学者按需调用。库可以提供预设了理论的工具供各流派选择，
但不能把其中任何一个设成不可绕开的前提。

**Why**：本库要服务的是民主计划经济这个大类下的**各个流派**，未来还要容纳
复杂经济学与基于 ABM 的计划模拟。基础层一旦焊进某一派的前提，别的流派就进不来，
而「共用学术基础设施」这个定位当场失效。

`插件边界.md:14` 早就写过「在经济学里插件边界约等于理论承诺边界」。
本条把它从插件边界的判准提升为基础层的硬约束。

**How to apply**：往固定层加任何东西之前，问一句「哪一派会不同意这条」。
答得上来就不能固定，只能做成工具。

### 四条不变量全部改为可选工具

**决策**：物料平衡、预算恒等、非负性、价格零次齐次不再全局强制。
它们是工具箱里的可选约束，学者按需启用。工具箱后续会扩充。

**Why**：审下来四条没有一条是中立的。

| 不变量 | 蕴含的理论预设 | 什么时候不成立 |
|---|---|---|
| 预算恒等 | 硬预算约束 | 信用创造、赤字融资、转移支付 |
| 价格零次齐次 | 货币中性，价格纯为实物中介 | 引入货币、名义计价债务；各生产主体价格非等比例变动时，「所有价格同乘 λ」在系统里根本不构成对称性 |
| 非负性 | 一切产出都是「好品」 | 废弃物与排放——坏品带负价格是环境经济学常规，而 v1 范围明写带排放扩展 |
| 物料平衡 | 期内封闭、无库存跨期 | `Economy` 从第一天就是 T 期的，有存量时本期消耗可以超过本期产出 |

价格零次齐次那条尤其重，它是李嘉图式的实质主张而非算术性质。

原来 `spec.md` 写「检查在全局强制执行，不通过时把结果标为无效，不照常输出」，
那是在协调方法由库掌控时写的。协调方法归学者之后，这句话有三个问题：
探索期的中间产出必然违反不变量，一律拒绝输出等于把学者赶走；
「标为无效」（透明）与「不输出」（守门）被捆在一起，后者与责任边界冲突；
以及上表那四条理论承诺。

**排除方案**：见 [被否决/不变量与指标.md](被否决/不变量与指标.md)

**How to apply**：学者逐条加约束，实验就逐步变严格，这本身就是控制变量。

### 理论承诺归 prefab，不归库

**决策**：库不设全局默认的约束集。复现某篇文献时启用哪几条不变量，
由那篇文献对应的 prefab 声明。学者从零搭建时自己选。

**Why**：默认全开等于库出厂自带一套理论；默认全关等于新用户零保护。
两难的出口是让理论承诺有明确的归属人——**是那篇论文，不是库**。

`插件边界.md:46` 已定 prefab 按文献命名（`hahnel_2020_slides`）。
那么「Hahnel 2020 假定预算恒等成立」是那篇论文的假设，库只是如实转述。

**How to apply**：每个 prefab 显式列出它启用的约束集，理由指向文献的哪一处。

### 差额恒算，但可计算才算，且命名中性

**决策**：库总是计算各条约束的差额并写进输出，无论学者有没有把它设为约束。
但两条限制：机制上无定义的不计算（劳动时间直接计算没有价格，
价格零次齐次对它是 N/A 不是 0），输出里必须能区分 N/A 与 0；
命名一律中性——叫「预算差额」不叫「预算恒等违反」。

**Why**：库算的量才可比（同一定义），学者报告的量各人一套。差额恒算保证输出里
永远有可比的数字。

命名中性是因为同一个数字对不同的人性质不同：预算差额 15%，
对一个人是 bug，对做信用创造实验的人**是研究对象本身**。
库给数字，不给判词——判词也是理论。

**How to apply**：输出与 API 里凡是描述约束结果的词，检查一遍有没有夹带评价。

### 不设固定的核心指标，比较基准由学者声明

**决策**：库不规定一组固定的核心指标。比较用哪个量作基准，由学者在比较时声明，
声明进 run manifest。库提供计算各种量的工具，不规定哪个是中心。

**Why**：比较不是库做的，是学者用库的工具做的。而比较的前提是双方共享一套标准，
那套标准只能由做比较的人选——拿市场的方式比劳动的方式本来就不成立。

原先列的五项核心指标同样条条带理论：「给定社会福利函数下的福利」要先承诺一个 SWF 形式；
「劳动成本」预设劳动是相关的成本尺度，而 Kantorovich 那一派要的是目标函数值；
「排放对上限」预设生态约束采取上限这个形式。

**覆盖**：本条收窄 [插件边界.md](插件边界.md) 2026-08-28
「机制层可插拔，数据模型与不变量固定」里的固定四项。固定项现为两项：
`Economy` 数据模型、确定性与种子化。

**How to apply**：`Evaluator` 的职责从「产出可比指标」改为「给定计划与声明的基准，算出那个量」。

### 可比性靠原始输出，不靠预先约定指标

（⚠ 可比性锚点的表述已于 2026-08-30 收窄为「同一个初始经济体加同一条演化规律」，
见 [演化规律.md](演化规律.md)。本条其余部分不变。）

**决策**：可比性由三件事支撑——同一份 `Economy`、同一套记录纪律、声明的比较基准进 manifest。
再加一条对输出的硬要求：**输出必须原始到足以事后重算任何指标**。

输出分三层：

| 输出 | 默认 | 用途 |
|---|---|---|
| 完整最终配置（每个生产单元的产出、每种投入用量、价格或劳动价值、逐期） | 恒出 | 可比性 |
| 过程摘要（轮数、是否收敛、墙钟时间） | 恒出 | 机制效率这条比较轴 |
| 逐轮轨迹 | 给了 `plan_of` 才有 | 复现与诊断，体积大 |

**Why**：比较基准自由之后，甲论文比排放、乙论文比劳动生产率，两篇之间会失去可比。
出路不是回去固定指标，而是**保留足够原始的输出，让任何人事后用任何尺重算**。

这比固定指标强：固定指标只保证大家用同一把尺，事后可重算保证任何尺都能量任何人的结果。

可比性要的是「最终配置 + 少量过程摘要」——「你 500 轮我 200 轮、产出相当」
这个比较里，轮数是过程量而且正是重点。完整逐轮轨迹是复现与诊断用的，不是可比性用的。

**How to apply**：阶段 4 的验收判据是「能不能从输出重建出任何一个指标」。
只存汇总不算通过。

### SFC 拆开：会计守恒律进工具箱，行为方程归学者

**决策**：后凯恩斯的存量流量一致（SFC）框架按两半处理。
会计纪律部分——每个存量是流量的累积、每笔流量有来处与去处、交易流量矩阵行列归零——
作为一条可选守恒律进不变量工具箱，与物料平衡并列。
Godley-Lavoie 那些消费函数、组合选择方程属于机制层，是学者的东西，不进基础层。

**Why**：SFC 的核心是会计纪律不是理论，它守的是金融量而不是实物量，与物料平衡同类。

货币在这个领域不是外来物，是设计变量：parecon 有消费信用，
Cockshott 的劳动券是明确的货币设计（不流通的劳动证书），阿连德的智利是货币经济。
「消费购买力从哪来、未花完的收入去哪」在任何一个民主计划方案里都要回答。

**How to apply**：判准是——**能陈述成一条守恒律的可以进工具箱，需要行为方程的一律留给学者**。
SFC 一旦被当成「一套模型」引进来，就会把后凯的行为假设带进基础层，那才是扩展过头。

本条需要的数据模型支撑是货币存量字段，与交互拓扑一同推迟到 v1 之后，
见 [纲领定位.md](纲领定位.md)。

## 2026-09-05

### 价格零次齐次是性质测试，不是差额

**决策**：「差额恒算」只覆盖物料平衡、预算、非负性三条，它们都能从一次运行的输出算出。
价格零次齐次做成性质测试工具 `check_homogeneity`，形态与 `check_determinism` 相同：
把协调方法的初始估值量按比例缩放后重跑，比较两次的实物层。
它只对暴露了「初始估值量」参数的协调方法可用。实现推迟到阶段 2。

**Why**：齐次性是关于协调方法的性质，不是关于一份计划的记账。
一份计划的输出里没有「齐次差额」这个量，把它与另外三条并列在同一条规则下，
实现时会卡住。

**部分收窄**：本条收窄 2026-08-28「差额恒算，但可计算才算，且命名中性」的覆盖范围。
那条对另外三条的规定不变。

### 参照解是以目标函数为参数的工具

**决策**：参照解定义为 `reference_solution(economy, objective) -> Plan`。
目标函数由学者声明，声明进 run manifest。库自带若干目标函数作为选项，不设默认。

**Why**：`spec.md` 说对照基准是集中式最优参照解，但「最优」对什么目标没有定义。
本文 2026-08-28「不设固定的核心指标」已经说明目标函数是理论承诺。
两条并不冲突，出口是把目标函数当参数，但这句话此前没写下来，
实现阶段 5 的人会自己发明一个。

**How to apply**：阶段 1.5 的最小参照解是 Leontief 技术下的线性规划，
目标从库自带选项里选一个并写进 manifest。
