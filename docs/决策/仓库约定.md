# 仓库约定

## 2026-08-28

### 代码全英文，中文只用于 docs

**决策**：标识符、注释、文档字符串、报错文案、测试名称一律英文。
`docs/` 下的文档与日常讨论用简体中文。

**Why**：目标用户是国际学术圈，副标题就是英文的
（见 [项目命名.md](项目命名.md)）。代码里出现中文标识符会直接把非中文读者挡在外面，
而本库的存在理由是降低使用门槛。

文档用中文不冲突：读文档的当前只有维护者，需要时再出英文版，
而代码一旦用中文写就没有「再出一版」这个选项。

**How to apply**：讨论里说「协调方法」，代码里写 `Procedure`。
术语的中英对应记在 [术语表.md](../术语表.md)。

## 2026-09-26

### 上游文献的原文不随仓库分发

**决策**：`docs/研究/文献/` 只保留出处与下载地址。JIE 2023 论文与 2020 会议幻灯片的 PDF，
以及两份的文本版本（论文的文字层抽取、幻灯片的逐页转录），从仓库与全部历史里移除。

**Why**：仓库准备转为公开。两份材料都由作者或会议方公开发布，但转载许可没有逐份核实：
JIE 由 Anser Press 出版，多为开放获取，仍要逐份确认；幻灯片是会议材料，没有写许可条款。
全文转录等于再分发全文，风险与 PDF 相同。
下载地址稳定，读者一条 `curl` 就能拿到原文，不分发的代价很小。

**排除方案**：
- 保留 PDF，只删转录 — 风险在 PDF 本身，删转录解决不了
- 核实许可后再决定 — 核实要联系出版方，而发布不该等这件事。核实了再加回来即可

**How to apply**：以后归档任何第三方文献，默认只记出处、DOI 与下载地址。
确认许可允许再分发之后，才把原文放进仓库。
