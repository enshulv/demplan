# 被否决：纲领定位

## 2026-08-28

### 在 v1 里实现一条市场基线作对照组

**否决**。

**提案**：除民主计划机制外，另实现一套市场出清机制作为实验对照组。
`Economy` 相应增加货币收支与市场出清残差字段。

**当初为什么想做**：评议人对任何机制设计工作都会问「compared to what」。
手里有一条市场基线，「同一经济体、五种程序、三条曲线」这个卖点才完整。

**排除理由**：定位改变之后这个理由不再成立。本库是民主计划经济的共用基础设施，
不是机制中立的比较平台。「compared to what」在这个定位下由集中式最优参照解回答，
而参照解是同一个 `Economy` 上可计算的上界，比市场基线硬。

市场基线还要额外承诺一套行为假设。那套假设会成为争议焦点，把讨论从机制本身移开。

代价也实在：多一套机制的实现工量，加上 `Economy` 为它长出一批别的机制用不到的字段。

**复活条件**：评议明确要求市场对照，且参照解不被接受为基准时。届时按机制层插件加入
（[插件边界.md](../插件边界.md)），`Economy` 的市场字段作为可选扩展，不进核心不变量。
