# 被否决：许可证

## 2026-08-28

### 用 Coopyleft（CoopCycle 许可证）

**否决**。

**提案**：采用法国送餐骑手合作社联盟 CoopCycle 自订的 Coopyleft 许可证，
只允许合作社与欧盟定义下的社会团结经济主体使用本库。

**当初为什么想做**：与本项目的领域立场一致。做民主计划经济的基础设施，
用一个把使用权交给合作社的许可证，姿态是自洽的。

**排除理由**：它按使用者的法律形态设限，因此不符合 OSI 的开源定义，
后果对学术库是具体的——conda-forge 与 Debian 收不了非 OSI 许可证；
不少大学的法务与 IT 只批 OSI 清单内的许可证；越来越多期刊的可复现性要求指定开放许可证；
别的库不能依赖它。

还有一条内部张力：本项目的定位是「共用学术基础设施」，
而按机构形态限制谁能用，与「共用」是相反方向。

**复活条件**：本库出现需要防止的具体商业挪用，且届时已有足够用户基础承受采用率损失时。
