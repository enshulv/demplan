# 被否决：项目命名

## 2026-08-28

以下候选按 crates.io、PyPI、GitHub 三处的实际占用情况逐个查过。

### 用项目本名 cybersyn

**否决**。

**提案**：直接用 Project Cybersyn 的项目名。

**当初为什么想做**：识别度最高，且结构上最贴本项目的定位——Cybersyn 本身就是
CHECO、Cyberstride、Cybernet、Opsroom 的伞，而本项目也是「比较 + 计算优化 + 外包装」的伞。
crates.io 与 PyPI 两处的包名都还空着。

**排除理由**：包名空着，但名字在相邻空间已被占两次。GitHub 搜索前排是
`project-cybersyn/cybersyn2` 等 Factorio 火车物流 mod；另有 `cybersyn-data` 组织，
即被 Snowflake 收购的经济数据公司。后者与本项目撞在同一个领域格子里。

**复活条件**：那两处占用消失时。实际上不会发生，不必等。

---

### 用 checo

**否决**。

**提案**：取 Cybersyn 的经济仿真组件 CHECO（CHilean ECOnomy）。crates.io 与 PyPI 均空。

**当初为什么想做**：功能类比最准。CHECO 就是个经济仿真器——给定经济体与政策，跑出轨迹，
与本库做的事一一对应。五个字母，好打好念。

**排除理由**：通用搜索撞两个高频词——西班牙语的「捷克」，以及 F1 车手 Sergio "Checo" Pérez。
名字本身也不像基础设施。

**复活条件**：无。已被 `cyberstride` 取代，功能类比的错配作为已知代价记在
[项目命名.md](../项目命名.md) 里。

---

### 谱系内的其余候选：synco 与 opsroom

**否决**。

**提案**：`synco`（项目的西班牙语原名 Proyecto Synco）或 `opsroom`（操作室）。

**当初为什么想做**：`synco` 是项目自己的名字，两音节好念；`opsroom` 与
[技术选型.md](../技术选型.md) 里已定的「TS/wasm 供可视化与人在环前端」直接呼应。

**排除理由**：`synco` 的 PyPI 包名已被占，且 GitHub 搜索被 `syncora-ai` 系列仓库淹没。
`opsroom` 三处都空，但对不知道这条谱系的人就是个 DevOps 作战室，语义被平庸化；
且它只盖前端那一层，对核心库偏。

**复活条件**：无。

---

### 用 parecon

**否决**。

**提案**：直接叫参与式经济学的通行缩写。crates.io 与 PyPI 均空。

**当初为什么想做**：运动内识别度最高，一望即知领域。

**排除理由**：把项目叫小了。按 [纲领定位.md](../纲领定位.md)，本库覆盖的是民主计划经济这个
领域，参与式计划只是其中一个学派；以学派命名会让 Cockshott 劳动时间与 Kantorovich
线性规划这类同领域方案看起来是外来户。

**复活条件**：无。这与已拍板的纲领定位直接冲突。

---

### 用希腊语或拉丁语抽象名词族

**否决**。

**提案**：`koinon`（希腊城邦联盟、共有之物）、`isegoria`（平等发言权）、
`oikonomia`（economy 的词源）、`consilium`（审议、议事会、计划）。

**当初为什么想做**：与 `mesa`、`Concordia` 同族——单词、抽象、不自我说明、
留得下扩展空间。`isegoria` 语义直接命中参与式计划的内核（每个参与者的提案平等进入迭代），
且占用最干净：GitHub 全站仅 15 个同名仓库，均不超过 1 星。
`consilium` 语义最全，一个词同时是审议、议事会和计划。

**排除理由**：Cybersyn 谱系确定之后，这一族失去了立足点——它们各自都是好名字，
但都不承载本领域的历史。另有两条各自的硬伤：`consilium` 的 PyPI 包名已被一个
LLM 辩论 CLI 占用，撞在同一个语义空间；`isegoria` 五音节，会议上口头引用会吃亏。

**复活条件**：决定放弃 Cybersyn 谱系时。
