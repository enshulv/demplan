# 项目命名

## 2026-08-28

### 项目定名 cyberstride

**决策**：项目名为 `cyberstride`。crate 名、Python 包名、仓库名统一用它。
英文副标题固定为 "shared research infrastructure for democratic economic planning"。

**这个名字是暂定的**，第一次发布之前都可以改。改名成本在没有下游用户时接近零，
所以不必现在锁死；但同一时刻只用一个名字，不要几种写法并存。

**Why**：名字取自 Project Cybersyn（智利，1971–73）的统计预测与预警组件 Cyberstride。
挂这条谱系的理由是领域同源：Cybersyn 是民主计划经济唯一一次真正进入生产运行的尝试。

不用项目本名 `cybersyn`，因为相邻空间已被占用：GitHub 搜索结果前排是 Factorio 的
火车物流 mod，另有 `cybersyn-data` 组织，即被 Snowflake 收购的经济数据公司。
后者撞在经济数据这一格上。

`cyberstride` 在 crates.io 与 PyPI 均未注册。GitHub 同名仓库 16 个，最高 2 星，
其中两个正是重建 Beer 系统的小项目——这个名字在圈内读得对，又没有形成品牌占用。

选名参照收藏夹「社会科学」分类里的六个库。那批库分两族：`mesa` 与 `Concordia`
是单词、不自我说明；`AgentSociety` 与 `AgentTorch` 是复合描述词、一看就懂。
本项目取前一族，与 [技术选型.md](技术选型.md) 里的对标对象 Concordia 同族。

**已知的错配**：Cyberstride 在原项目里做的是监测与预警，而经济仿真是另一个组件 CHECO。
论功能类比，`checo` 更准。选 `cyberstride` 是拿类比精度换名字质量，
详见 [被否决/项目命名.md](被否决/项目命名.md)。

**How to apply**：名字不自我解释，凡是首次出现的场合都要带副标题。
仓库描述、crate 描述、PyPI summary 三处用同一句英文，不各写一套。
