# WIOD 字段映射：`Economy` 缺什么

按 [决策/分期与粒度.md](../决策/分期与粒度.md) 2026-09-05 的要求，在阶段 2 锁死差额定义之前，
先列出把 WIOD 2016 版装进 `Economy` 会缺什么。**本文只列缺口，不写代码，也不定方案。**

⚠ 本文根据对 WIOD 2016 版公开文档的记忆写成，**没有核对原始文件**。
阶段 3 动手前先下载一份对着核，标 ⚠ 的行尤其要核。

## WIOD 2016 版提供什么

| 表 | 内容 | 维度 |
|---|---|---|
| WIOT | 世界投入产出表，行业×行业，2000 到 2014 年逐年 | 43 个经济体加「世界其他」，每个 56 个 ISIC Rev.4 行业，中间使用矩阵 2464×2464 |
| WIOT 最终需求 | 五类：居民消费、非营利机构消费、政府消费、固定资本形成、库存变动 | 5 类 × 44 个经济体 |
| WIOT 增加值行 | 税减补贴、雇员报酬、其他净税、固定资本消耗、营业盈余等（⚠ 具体行名要核） | 按行业 |
| WIOT 国际运输差额行 | ⚠ | 按行业 |
| SEA | 社会经济账户：就业人数、工时、雇员报酬、资本存量、按技能分的工时（⚠ 2016 版是否仍分三级技能要核） | 经济体 × 行业 × 年 |
| 环境账户 | 2016 版本体不含。CO₂ 排放另有 2019 年发布的补充数据集（⚠ 出处要核） | 经济体 × 行业 × 年 |

全部数值以**当年价格的百万美元**计。这一点决定了下面大半的缺口。

## 逐项映射

| WIOD 的东西 | 落到 `Economy` 哪里 | 缺口 |
|---|---|---|
| 行业×经济体 | 商品一行（类别：中间品）加生产单元一行，`unit_group` = 行业 | 经济体这个维度没有位置。`unit_group` 只有一层，「按行业分组」与「按经济体分组」不能同时表达 |
| 中间使用矩阵 `Z` | `input_commodity` 与 `input_coefficient`，Leontief 系数 `a_ij = Z_ij / x_j` | 2464×2464 稠密，非零约 40%（⚠），扁平数组约 240 万条。规模在 v1 范围内 |
| 居民消费 | 消费单元，每个经济体一个，`consumption` 列映射到全部 2464 种商品 | 消费单元的分组只有 `consumer_group` 一层，「居民 / 政府 / 非营利」与「哪个经济体」不能同时表达 |
| 政府消费、非营利消费 | 公共品的 `provision` | WIOD 的政府消费按行业计，不是按「公共品」这个类别计。同一行业的产出既进居民消费也进政府消费，**一种商品同时是私人品与公共品**，`commodity_kind` 单值放不下 |
| 固定资本形成 | 无处放 | 资本存量已推迟到 v1 之后。阶段 3 只能把它当成一类最终消费 |
| 库存变动 | 无处放 | 可以为负。物料平衡差额在期内封闭的定义下会把它算成差额，那是数据的性质不是机制的缺陷。可能的落点是 `endowment` 列取负值，但 `endowment` 的定义是「本期不经生产就可用的数量」，负值要另立解释 |
| 雇员报酬 | 劳动商品的投入用量 | 单位是货币不是工时。SEA 有工时，但 WIOT 的劳动投入是报酬，两者比例是工资率，是数据不是理论。要决定劳动商品以货币计还是以工时计 |
| 固定资本消耗、营业盈余 | 无处放 | 不是商品。v1 忽略即可，但物料平衡里「投入之和不等于产出」的差额就来自这里，差额定义要能说清这一部分 |
| 税减补贴 | 无处放 | 可以为负。同上 |
| 进出口 | 经济体之间的中间使用与最终需求，已在 `Z` 与最终需求里 | 无缺口。WIOT 是一张封闭的世界表 |
| 「世界其他」 | 一个经济体 | 无缺口 |
| 自然资源 | 无 | WIOD 没有实物的自然资源账户。要么留空，要么从别处接（EXIOBASE 有） |
| CO₂ 排放 | 需要新商品类别 | 排放是「坏品」：产出为负效用，有上限约束。`commodity_kind` 加一个值即可，但**非负性差额对它的定义要反过来**，阶段 2 定差额时要留这个口子 |
| 工时、就业人数 | `unit_extra` | 无缺口 |
| 年份 | `period` | 无缺口。逐年表可以直接当多期数据，但 WIOD 的相邻年份不是同一条演化规律推出来的，把它们当轨迹用要在文档里说明 |

## 归纳：真正的缺口有四条

1. **两层分组**。生产单元与消费单元都需要「经济体」加「行业 / 类型」两个维度。
   `unit_group` 与 `consumer_group` 各只有一层。候选：把经济体放进 `extra`（`unit_extra["region"]`），
   固定列不动。这条阶段 3 再定。
2. **一种商品同时是私人品与公共品**。`commodity_kind` 单值放不下 WIOD 的政府消费。
   候选：类别只标「谁生产它」（中间品），私人与公共的区分挪到 `Plan` 的消费侧
   （`consumption` 与 `provision` 本来就是两列）。这会改 dep1ex 的类别标记方式，
   **阶段 2 定物料平衡差额时要按这个可能性写，别把「公共品需求除以消费单元数」焊进差额**。
3. **负项**。库存变动、补贴、坏品。阶段 2 的非负性差额与物料平衡差额要能对负项给出定义，
   而不是报错。
4. **货币计价**。WIOD 的「数量」是当年价格下的货币额。`Economy` 的 f64 列不管单位，
   这不是结构缺口，但 `Plan.valuation` 里的价格对 WIOD 经济体就是相对价格指数，
   文档要说明。

自然资源账户与资本存量是数据缺失，不是 `Economy` 的缺口。

## 对阶段 2 的直接要求

- 物料平衡差额：按商品算 `output + endowment − input_use − consumption − provision`，
  允许任一项为负，差额是带符号的数，不做绝对值
- 非负性差额：按商品类别取符号约定，坏品的「非负」是「非正」
- 预算差额：WIOD 消费单元没有 `entitlement`，`income` 也没有，差额为 N/A。这是 N/A 的第一个真实用例
